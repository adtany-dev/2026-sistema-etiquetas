Proyecto académico C# Windows Forms (.NET 8).
Abre SistemaEtiquetas.csproj en Visual Studio 2022 con la carga de trabajo Desarrollo de escritorio de .NET y ejecuta con F5.
Presentacion/FrmEtiquetas.cs = interfaz y eventos.
Negocio/EtiquetaService.cs = validaciones y generación de secuencia.
Prueba con producto MOD-2048, lote LOTE-26A y cantidad 1. La impresión física se simula; requiere configuración para impresora real.
